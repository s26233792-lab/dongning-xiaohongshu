# Dongning Xiaohongshu

## Overview

这个技能用于在小红书进行真人式抓取与爆点分析，不停留在标题层，而是结合正文和评论区提炼高互动原因。  
核心目标是输出可复用的内容结构，而不是只做信息搬运。

## Trigger Conditions

当用户出现以下诉求时使用本技能：
- 搜索小红书某主题并找热门帖
- 总结爆款内容共性、爆点、话题结构
- 输出选题方向、文案框架、可复制模板
- 要求“拟人抓取”“像真人一样浏览”

## Workflow

### 1. 启动与会话约束（硬规则）

必须遵守：
- 只开一个浏览器实例
- 允许同一浏览器下多开标签
- 使用持久化会话，优先 `default`

推荐命令：
```bash
playwright-cli list
playwright-cli -s=default open xiaohongshu.com --headed --persistent
playwright-cli -s=default tab-list
```

如果 `default` 已存在则复用，不要再次 `open` 新实例。

### 2. 搜索并收集候选热门帖

1. 进入小红书搜索页并输入关键词（例如 `个人成长`）。
2. 读取结果页快照，抓取：
- 帖子标题
- 帖子链接
- 点赞量（如 `5.4万`）
- 发布时间（如可见）
3. 首轮样本建议 8-15 条，优先高互动帖子。

常用动作：
```bash
playwright-cli -s=default goto https://www.xiaohongshu.com/
playwright-cli -s=default fill e9 个人成长
playwright-cli -s=default press Enter
```

### 3. 同浏览器多标签深读样本

对高互动样本逐条使用 `tab-new` 打开，读取正文与评论区信号：
- 正文是否有明确方法（编号、清单、步骤）
- 是否先共情再给解法（情绪钩子）
- 评论区争议点与共鸣点（拉高互动的关键）
- 收藏导向信息（可执行、可保存）

常用动作：
```bash
playwright-cli -s=default tab-new "https://www.xiaohongshu.com/explore/..."
playwright-cli -s=default tab-list
```

### 4. 爆点拆解维度

至少覆盖以下 6 个维度：
1. 标题爆点：痛点词、结果词、时间词、数字化表达
2. 叙事爆点：是否“先扎心后给路”
3. 方法爆点：清单化、步骤化、低门槛可执行
4. 价值爆点：成长是否被重述为自由感/掌控感
5. 互动爆点：是否存在可讨论争议（非对错争吵）
6. 人群爆点：标签是否精准命中（如打工人、女性成长、自律焦虑）

### 5. 输出结论与可复用公式

输出时给出：
- 热门样本列表（标题 + 互动量 + 链接）
- 共性规律（按频次排序）
- 爆款公式（可直接套用）
- 反例提醒（高风险、低信任写法）

推荐公式：
`情绪痛点 + 量化承诺 + 最小行动清单 + 身份标签 + 轻争议问题`

## Quality Bar

最终回答必须满足：
- 明确抓取日期与关键词
- 标注样本数量（避免“看了几条就下结论”）
- 区分“搜索页互动量”与“单帖页互动量”
- 不编造未抓取的数据，不虚构账号观点
