# dongning-xiaohongshu

一个用于 **小红书热门内容抓取与爆点分析** 的 Codex Skill。  
它的作用不是简单摘抄帖子，而是通过“真人浏览式”流程，提炼可复用的爆款结构与选题公式。

## 这是干嘛用的

当你需要做以下事情时，用这个 skill：
- 搜索某个主题（如个人成长、情绪管理、职场）在小红书的热门帖子
- 分析热门内容为什么爆（标题、叙事、方法、互动机制）
- 输出可复用的内容框架、选题方向和文案公式

## 核心能力

- 基于 `playwright-cli` 进行拟人化抓取
- 单浏览器持久会话，多标签并行深读样本
- 结合标题、正文、评论区做完整爆点拆解
- 输出结构化结论，而不是零散观点

## 工作方式（简版）

1. 启动并复用同一浏览器会话（`--headed --persistent`）
2. 搜索关键词并收集高互动样本（标题/链接/互动量）
3. 多标签进入样本帖正文与评论区深读
4. 按维度输出爆点分析与可复用公式

## 输出内容包含

- 热门样本清单（标题 + 互动量 + 链接）
- 共性爆点（按频次/强度）
- 爆款结构公式（可直接套用）
- 反例提醒（容易翻车的写法）

## 适用对象

- 内容运营 / 新媒体编辑
- 个人 IP 账号运营者
- 需要快速做平台选题研究的人
